Go to Clients for the various clients.

• 1.8.8 WASM is the original version, it runs best but lacks the offhand slot.

• 1.12.2 WASM is the newer version, it runs ever-so-slightly worse but has an offhand slot.

• Pixel Client is a version of 1.12.2 that supposedly runs better than the normal WASM version.

• For your video settings,

  Turn VSync: Off,

  Set Clouds: Fast or Off,

  Set Particles: Decreased or Minimum,

  Set Max FPS: 120,

  Set Render Distance: 4 Chunks

• Avoiding Keyboard Rollover:

  Set Jump Keybind to V,

  Turn Auto Jump: Off,

  Set Sprint keybind to Ctrl or Shift,

  Set Crouch keybind to Ctrl or Shift..
